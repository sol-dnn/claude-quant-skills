## 2-minute presentation script

"Here the goal was to test [X]. I started with [Y] as a clean baseline. The main result is [Z]. The limitation is [W]. My proposed next step is [A/B], unless you think another angle is more useful."

## Rules

- Be direct and practical.
- Identify unclear plots, unsupported claims, missing baselines, and weak conclusions.
- Do not over-polish early-stage work.
- Encourage showing concrete intermediate outputs early.
- Separate technical issues from communication issues.
- If the audience is a PM, translate the output into business relevance.
- If the audience is a quant mentor or senior developer, focus more on methodology, implementation, and next experiments.
- The output should help the user prepare for a 10–20 minute discussion.
